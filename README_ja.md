# Configurable Reports ブロック — Chart.js フォーク

[English](README.md)

[jleyva/moodle-block_configurablereports](https://github.com/jleyva/moodle-block_configurablereports)（v5.2.0）のフォークです。Chart.js によるグラフ描画機能と、テンプレートの拡張機能を追加しています。

## このフォークについて

`chartjs` ブランチでは、オリジナルのプラグインに以下の機能を追加しています。

- **Chart.js 描画エンジン** — 管理者設定で pChart / Chart.js を切り替え可能
- **既存グラフプラグインの拡張** — 棒グラフ、折れ線グラフ、円グラフに新オプションを追加
- **新規グラフプラグイン** — レーダー、散布図、タイルチャート、コンボチャートを追加
- **テンプレート機能の改善** — `##graph:N##` プレースホルダーのサポートと GUI レイアウトビルダーの追加

> **注意**: `MOODLE_4x_STABLE` ブランチはアップストリームのリポジトリと同期されています。カスタム機能はすべて `chartjs` ブランチに含まれています。

## chartjs ブランチ

### 動作要件

- Moodle 4.1 以降（Moodle 4.5+ 推奨）
- PHP 8.1+
- Chart.js は Moodle コアに同梱（`core/chartjs`）— 別途インストール不要

### インストール

1. `chartjs` ブランチをクローンまたはダウンロード
2. Moodle の `blocks/configurable_reports/` にファイルをコピー
3. `/admin/index.php` にアクセスしてアップグレードを完了

### 設定

**サイト管理 → プラグイン → ブロック → Configurable Reports** から設定できます。

| 設定 | 選択肢 | 説明 |
|---|---|---|
| グラフライブラリ | pChart（デフォルト）/ Chart.js | 全グラフプラグインの描画エンジン |
| テンプレートエディタ | Classic（デフォルト）/ GUIビルダー | テンプレートコンポーネントの編集モード |

### 新規・拡張グラフプラグイン

#### 拡張済みプラグイン

| プラグイン | 追加オプション |
|---|---|
| 棒グラフ（Bar） | 方向（縦/横）、グループ化（grouped/stacked）、ヒストグラムモード、データセット逆順 |
| 折れ線グラフ（Line） | 最大5系列・系列ごとの集計方法、Y2軸フラグ、スムーズ曲線、エリア塗りつぶし |
| 円グラフ（Pie） | ドーナツスタイル、幅・高さ設定 |

#### 新規プラグイン

| プラグイン | 説明 |
|---|---|
| レーダーチャート（Radar） | 系列ごとの集計機能付きレーダー/スパイダーチャート（Chart.js 専用） |
| 散布図（Scatter） | ラベル列による色分けオプション付き散布図。r列を指定するとバブルチャートモードに切り替わる |
| タイルチャート（Tiled chart） | グループキーでタイル分割して並べて表示。棒・折れ線・エリア・円・ドーナツ・レーダーに対応（最大5系列・集計機能付き） |
| タイル散布図（Tiled scatter） | グループキーでタイル分割した散布図/バブルチャート。ラベル列で色分け可能 |
| コンボチャート（Combo） | 棒グラフ + 折れ線グラフの混合。デュアルY軸対応 |

### テンプレート機能の改善

#### プレースホルダー

テンプレートのヘッダーとフッターで以下のプレースホルダーが使用できます。

| プレースホルダー | 説明 |
|---|---|
| `##graphs##` | 全グラフを縦に並べて表示 |
| `##graph:1##` | 最初のグラフのみ表示 |
| `##graph:N##` | N番目のグラフ（1始まり・動的） |
| `##reporttable##` | データテーブル |
| `##reportname##` | レポート名 |
| `##reportsummary##` | レポートの説明 |
| `##exportoptions##` | エクスポートボタン |
| `##calculationstable##` | 計算テーブル |
| `##pagination##` | ページネーション |

**例 — グラフを横並びで表示（ヘッダーに記述）:**

```html
<div style="display:flex; gap:16px;">
  <div style="flex:1;">##graph:1##</div>
  <div style="flex:1;">##graph:2##</div>
</div>
```

#### GUIビルダー

**テンプレートエディタ** を **GUIビルダー** に設定すると、行×カラム形式のレイアウトエディタが使用できます。各セルにプレースホルダーやカスタムHTMLを配置できます。レイアウトはJSONで保存され、いつでも再編集可能です。
